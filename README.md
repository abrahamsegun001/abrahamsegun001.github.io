# Abraham Oluwasegun

This repository contains the source code for [my personal website](https://abrahamsegun001.github.io/).

I'm an MSc Data Science researcher at the Pan African University (PAUSTI), with a background in mathematics. My current work focuses on modelling cortical activity from neural recordings, particularly the challenge of understanding what a model can reliably tell us about the mechanisms behind observed activity.

The website brings together my research projects, publications, teaching experience, and selected academic activities.

## Running locally

The site is built with HTML, CSS, and JavaScript. No installation or build step is needed. Clone the repository and open `index.html` in a browser.
